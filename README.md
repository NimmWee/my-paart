# Мой вклад в «Авитошу»

Здесь собрана моя backend-часть проекта: ядро виртуального питомца «Авитоша».

Я реализовал модели питомца, ежедневного состояния и инвентаря; бизнес-логику ухода, XP, уровней и событий; PostgreSQL-репозитории и миграции; защищённый Pet API для получения питомца, использования предметов и просмотра daily summary. Также добавил транзакционную обработку с защитой от повторного использования предметов, OpenAPI-контракт, тесты и smoke-проверку.

В репозитории находятся только исходные файлы моей реализации: `app/backend` и `contribution.txt`.
